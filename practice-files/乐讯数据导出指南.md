# 乐讯数据导出指南

> 用途：把乐讯平台的靓号数据和活动数据导出来，用于课程实战和简历项目。
> 三个方法从易到难，按你的系统实际情况选一个。

---

## 方法一：复制粘贴法（任何系统都能用）

**适合**：后台列表能复制文字的情况（右键复制 / Ctrl+A 全选 / Ctrl+C）。

**步骤：**
1. 打开乐讯后台的靓号管理/活动管理列表页
2. 用鼠标框选列表内容（或 Ctrl+A 全选），Ctrl+C 复制
3. 打开 Excel/WPS 表格，点 A1 单元格，Ctrl+V 粘贴
4. 检查粘贴结果：列有没有对齐、有没有漏行
5. 删掉不需要的列（比如操作按钮列），把表头改成规范名称（见下方字段清单）
6. 另存为 .xlsx 文件，命名规范：`项目1-靓号定价分析-原始数据.xlsx`

**注意：**
- 如果一页显示不完，翻页重复上述操作，粘贴到同一张表的下一段
- 如果列表不让复制：试试先选中列表文字 → 拖动选中 → 右键复制；或按 F12 打开开发者工具截图 OCR（不推荐，最后手段）

## 方法二：后台导出按钮（如果有）

**适合**：后台有"导出""下载""数据导出"按钮的情况。

**步骤：**
1. 在列表页找"导出"或"下载"按钮（通常在列表上方或右上角）
2. 选择导出格式（优先 Excel/CSV）
3. 下载后打开检查：行数对不对、字段齐不齐（对照下方字段清单）
4. 补齐缺失字段后保存归档

## 方法三：找有权限的同事要

**适合**：自己没有后台权限的情况。

**话术参考：**"我要做活动数据复盘，需要最近半年的活动参与数据，方便导一份给我吗？"——提前按字段清单说清楚要哪几列。

## 字段清单（导出时对照检查）

**靓号数据**（项目一用）：

| 字段 | 示例 | 说明 |
|------|------|------|
| 号码 | 48360054 | 5-8位数字 |
| 位数 | 8 | 没有的话用LEN(号码)自己算 |
| 规律类型 | 888/顺子/豹子/AABB/普通 | 没有的话自己标注 |
| 价格 | 88 | 乐元 |
| 上架状态 | 在售/已售/下架 | 必须要有，否则分析不了动销 |
| 上架日期 | 2026-05-20 | 没有的话先空着 |

## 隐私提醒

- 导出时**用户ID和昵称涉及用户隐私**，只用于分析，不要外传
- 放进简历的项目报告里，用"用户A/用户B"或ID打码代替真实昵称

## 没导出成功怎么办

- 用课程提供的**备用模拟数据**（靓号库.csv / 活动明细.csv）先练流程
- 数据导出好之后，把真实数据跑一遍同样的分析即可
- 模拟数据的结构、字段、价格分布与真实数据一致，操作步骤零改动
